# بوت البانك 🏦

مشروع بوت Discord عربي باقتصاد افتراضي وقاعدة بيانات PostgreSQL ولوحة ويب بـ FastAPI.

## الأنظمة الموجودة

- **الاقتصاد:** المحفظة والبنك، إيداع وسحب، تحويل بين الأعضاء، مكافأة يومية مع سلسلة استلام، عمل مع وقت انتظار، سجل آخر العمليات، ترتيب الثروات، ومستويات وخبرة.
- **المتجر والمخزون:** عرض العناصر وشراؤها، عرض المخزون، وصندوق كنز قابل للفتح.
- **المغامرات والألعاب:** مغامرة مع غنائم/احتمال خسارة، ورهان بعملات افتراضية.
- **السوق الافتراضي:** أصول تجريبية، أسعار تتغير دوريًا، شراء وبيع وحدات، ومحفظة الأسهم.
- **النقابات:** إنشاء نقابة بتكلفة، قائمة النقابات، الانضمام، عرض معلومات النقابة، وخزينة تبرعات.
- **المواسم:** نقاط موسمية من اكتساب الخبرة، لوحة ترتيب، وتدوير الموسم عند انتهائه.
- **لوحة الموقع:** إحصاءات عامة، قائمة المتصدرين، تسجيل دخول Discord اختياري، وصفحة حساب.

> العملات والأسهم داخل المشروع افتراضية فقط، ولا تمثل أموالًا أو استثمارات حقيقية. هذا إصدار أول متكامل قابل للتطوير، وليس منتجًا تجاريًا مدققًا أمنيًا أو ماليًا.

## النشر على Render

### خدمة البوت (Background Worker)
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Environment Variables:
  - `DISCORD_TOKEN`: توكن البوت من Discord Developer Portal.
  - `DATABASE_URL`: رابط PostgreSQL الداخلي من Render.
  - `GUILD_ID`: معرّف سيرفر الاختبار (اختياري، يسرّع ظهور أوامر السلاش).
  - `STARTING_BALANCE`: رصيد البداية، مثل `500`.

### خدمة الموقع (Web Service)
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn dashboard:app --host 0.0.0.0 --port $PORT`
- Environment Variables:
  - `DATABASE_URL`: نفس قاعدة البيانات.
  - `SESSION_SECRET`: قيمة طويلة عشوائية.
  - `DISCORD_CLIENT_ID` و`DISCORD_CLIENT_SECRET`.
  - `DISCORD_REDIRECT_URI`: `https://YOUR-WEB-SERVICE.onrender.com/oauth/callback`

في Discord Developer Portal أضف رابط إعادة التوجيه نفسه ضمن OAuth2 Redirects. لا ترفع التوكنات أو كلمات المرور إلى GitHub.

## ملاحظات

- الأوامر تُزامَن مع `GUILD_ID` إن كان مضبوطًا، وإلا تُزامَن عالميًا وقد يستغرق ظهورها وقتًا أطول.
- السوق الافتراضي يحدّث الأسعار كل 6 ساعات أثناء تشغيل العامل.
- قاعدة البيانات تُنشأ جداولها تلقائيًا عند تشغيل البوت. احتفظ بنسخة احتياطية من قاعدة البيانات قبل استبدال ملفات مشروع قائم.
