# مملكة الاقتصاد — Discord Bot + Dashboard

مشروع بداية لبوت اقتصاد عربي في Discord مع لوحة ويب، مصمم للنشر عبر GitHub وRender.

## ما الموجود في هذه النسخة؟

- أوامر سلاش عربية: `/رصيدي`، `/يومي`، `/عمل`، `/إيداع`، `/سحب`، `/تحويل`، `/المتصدرين`، `/سوق`، `/مساعدة`.
- قاعدة PostgreSQL دائمة للأرصدة وسجل العمليات.
- معاملات مالية أساسية تستخدم قفل الصفوف لتقليل مشاكل التحويلات المتزامنة.
- لوحة ويب تعرض إحصائيات الاقتصاد والمتصدرين.
- مسار تسجيل دخول Discord OAuth مبدئي.
- `render.yaml` لتجهيز خدمات Render.

هذه **نسخة تأسيسية قابلة للتشغيل وليست كل الأنظمة النهائية**. التداول الفعلي داخل اللعبة، المخزون، النقابات، المهمات، المواسم ولوحة الإدارة تحتاج أن تضاف واختبارها في مراحل لاحقة.

## 1) أنشئ تطبيق Discord

1. افتح Discord Developer Portal وأنشئ Application.
2. من Bot أنشئ بوتًا وانسخ Token. لا تشاركه مع أحد ولا ترفعه إلى GitHub.
3. فعّل استخدام البوت وأضفه إلى سيرفرك بصلاحيات مناسبة.
4. انسخ Application ID لاستخدامه في لوحة OAuth.
5. للحصول على ظهور سريع لأوامر السلاش، ضع Server ID في `GUILD_ID` أثناء التطوير.

## 2) ارفع المشروع إلى GitHub

1. أنشئ مستودعًا جديدًا.
2. ارفع الملفات الموجودة في هذا المجلد.
3. تأكد أن `.env` وToken الحقيقي غير موجودين في المستودع.

## 3) انشر على Render

1. من Render اختر **New → Blueprint** واربط مستودع GitHub.
2. راجع `render.yaml` والخطط قبل تأكيد الإنشاء. قد تختلف الخطط والأسعار المتاحة حسب حسابك ومنطقتك.
3. أدخل `DISCORD_TOKEN` و`GUILD_ID` عندما يطلبهما Render.
4. أكمل إعداد `DISCORD_CLIENT_ID` و`DISCORD_CLIENT_SECRET` لخدمة الويب.
5. بعد إنشاء خدمة الويب، انسخ عنوانها وضعه في `DISCORD_REDIRECT_URI` هكذا:
   `https://YOUR-WEB-SERVICE.onrender.com/oauth/callback`
6. في Discord Developer Portal، أضف نفس عنوان callback في OAuth2 Redirects.

## 4) تشغيل محلي اختياري

Python 3.11 أو أحدث:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

أنشئ `.env` من `.env.example` واضبط متغيرات البيئة في الطرفية أو عبر أداة إدارة متغيرات البيئة، ثم شغّل البوت واللوحة كلًا في عملية منفصلة:

```bash
python bot.py
uvicorn dashboard:app --reload
```

## تنبيهات مهمة

- استخدم أرصدة وأصولًا افتراضية فقط؛ لا توجد أموال حقيقية أو تكامل مع وسطاء تداول.
- لا تضع توكن Discord أو سر OAuth في الكود أو GitHub.
- قبل الإطلاق العام، اختبر التحويلات المتزامنة، النسخ الاحتياطية، حدود الأوامر، وصلاحيات الإدارة.
- `SESSION_SECRET` يجب أن يكون طويلًا وعشوائيًا في الإنتاج.
- لوحة التحكم الحالية تعرض إحصائيات عامة؛ تسجيل الدخول موجود كأساس، لكن صلاحيات الإدارة والتخصيص الشخصي لم تكتمل بعد.
